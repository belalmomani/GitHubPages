LibLink: مدير مستودعات GitHub في جيبك

تطبيق لإدارة Git وGitHub من أندرويد وويندوز وماك ولينكس. مجاني، ويدعم العربية والإنجليزية.

اطلب التنزيلسياسة خصوصية التطبيق

التوفّر على Google Play: قريبًا. تواصل معنا للحصول على أحدث نسخة.

المزايا

إدارة Git كاملة

استنساخ المستودعات، commit وpush وpull، الفروع والدمج، كل ذلك من هاتفك أو حاسوبك.

بناء وإصدارات

شغّل GitHub Actions، تابع حالة البناء، نزّل ملف APK الناتج وأدر الإصدارات وملاحظاتها.

حسابات متعددة

أضف أكثر من حساب GitHub وشاهد كل المستودعات معًا، وفوق كل مستودع حسابه.

إدارة الأسرار بالجملة

أضف مجموعة Secrets لكل المستودعات أو لمحدّدة منها، وبخيار «أضف الناقص فقط» دون تعديل الموجود.

محرر ملفات

تحرير مع تلوين الصيغة وبحث واستبدال ومسودات تُحفظ تلقائيًا، واستيراد ملفات ومجلدات.

أمان وتراجع

سلة محذوفات واسترجاع للعمليات، وفحص «الطبيب» يشخّص مشاكل الاتصال والصلاحيات.

أندرويد وسطح المكتب

نسخة أندرويد، ونسخة ويندوز وماك ولينكس بنفس الوظائف تقريبًا.

واجهة عربية وإنجليزية

كل زر عليه شرح بالعربية والإنجليزية، ودعم كامل لاتجاه RTL.

كيف يعمل؟

  1. تُنشئ Personal Access Token من حسابك في GitHub بأقل الصلاحيات اللازمة.
  2. تضيفه في التطبيق، ويحفظ التطبيق حسابك على جهازك فقط.
  3. تتصل الواجهة مباشرة بواجهات GitHub الرسمية (REST وGraphQL)، دون وسيط.

التطبيق مستقل وغير تابع لـ GitHub ولا ترعاه GitHub أو Google. وهو يعرض إعلانات محدودة (حتى 3 إعلانات عادية يوميًا) لدعم التطوير.
