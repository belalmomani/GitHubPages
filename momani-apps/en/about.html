About us

Momani Apps is an independent developer project from Jordan, building practical tools for developers, starting with LibLink.

Our vision

Developer tools should be easy, fast and clear in your own language, and respect user privacy and permissions.

Principles

  • Official GitHub APIs only, with least-privilege access.
  • We never expose secret values and never store tokens on our servers.
  • We respect rate limits and handle network errors clearly.
  • Every button is explained in Arabic and English.
