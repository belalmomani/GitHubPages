Features

Full Git workflow

Clone repositories, commit, push and pull, work with branches and merges, from your phone or computer.

Builds and releases

Run GitHub Actions, watch build status, download the resulting APK and manage releases and notes.

Multiple accounts

Add several GitHub accounts and see all repositories together, with the account shown above each one.

Bulk secrets manager

Add a set of Secrets to all or selected repositories, with an “add missing only” mode that never touches existing ones.

File editor

Syntax highlighting, find and replace, auto-saved drafts, and file or folder import.

Safety and undo

A trash with restore, undoable operations, and a Doctor that diagnoses connection and permission problems.

Android and desktop

An Android app plus Windows, macOS and Linux apps with nearly the same features.

Arabic and English UI

Every button has guidance text in Arabic and English, with full RTL support.

How it works

  1. Create a Personal Access Token in your GitHub account with the minimum scopes needed.
  2. Add it in the app; your account is stored on your device only.
  3. The app talks directly to GitHub's official APIs (REST and GraphQL), with no middleman.

LibLink is independent and is not affiliated with, endorsed or sponsored by GitHub or Google. It shows a limited number of ads (up to 3 regular ads per day) to support development.
