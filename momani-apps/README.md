# Momani Apps website (momani-apps/)
Static site (Arabic default, English in /en). No build step.

Publish: put this folder at the root of the GitHubPages repo -> Settings > Pages > Deploy from branch (main, / root).
URL: https://belalmomani.github.io/GitHubPages/momani-apps/

SEO: add https://belalmomani.github.io/GitHubPages/ as a URL-prefix property in Google Search Console, then submit
momani-apps/sitemap.xml. (robots.txt is only honored at a domain root; the sitemap submission is what matters here.)
