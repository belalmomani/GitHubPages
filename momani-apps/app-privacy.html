LibLink — Privacy Policy

Last updated: 2026-11-24 · Developer: Belal Momani · Contact: bilalalmomani90@gmail.com

LibLink ("the app") is a GitHub repository manager (Git operations, builds, releases, library of links). This policy explains what data the app handles. We do not run our own server and we do not sell your data. LibLink is an independent app and is not affiliated with, endorsed by or sponsored by GitHub, Inc. or Google LLC. "GitHub" is a trademark of GitHub, Inc.

1. Data stored only on your device

These items are kept in the app's private storage on your device and are never sent to us:

  • Your GitHub username, your GitHub Personal Access Token, and the author name/email you use for commits.
  • Project list, repository files you clone or create, build and release history, drafts, Library links and settings.
  • Optionally, signing-key details you choose to remember for re-signing an APK.

The token is protected by Android's app sandbox and is excluded from Android backups. Deleting the app's data or uninstalling the app removes all of it.

2. Data sent to GitHub (at your request)

When you pull, push, clone, start a build, download a build output or list repositories, the app sends your token and the requested content directly to GitHub (github.com, api.github.com) over HTTPS. GitHub processes it under GitHub's Privacy Statement. We never receive this data.

3. Optional cloud sync (Firebase / Google)

If — and only if — you create an account inside the app (Settings → Cloud sync), the app uses Google Firebase Authentication and Cloud Firestore to keep your devices in sync. Stored for your account: your email address, a user ID, your password (handled and hashed by Firebase; we cannot read it), your Library items, project names and repository URLs, and settings (GitHub username, commit author name/email, language). Your GitHub token is uploaded only if you switch on "sync token", and it is encrypted on your device with a passphrase that is never sent anywhere. Firebase may process technical data such as IP address and installation identifiers to operate the service; see Firebase privacy information. Using the app without an account sends nothing to Firebase.

4. Advertising (versions with ads)

Some versions show banner ads from Start.io. The Start.io SDK may collect and use your Android advertising ID, IP address (and the approximate location derived from it), device and app information, and diagnostics, for advertising and analytics. The app asks whether you allow personalized ads; you can change your choice any time in Settings, and you can reset or delete your advertising ID in Android settings. See Start.io's Privacy Policy. The app contains no other advertising or analytics SDKs.

5. Permissions

  • Internet / network state — to talk to GitHub, Firebase and the ad network.
  • Notifications — to tell you when a build finishes.
  • Advertising ID — used by the ad network (ad versions only).

The app does not access your contacts, camera, microphone, location, SMS or call logs.

6. Retention and deletion

  • On-device data: kept until you delete it or uninstall the app. Files you delete inside the app stay in an in-app recycle bin for 3 days.
  • Cloud-sync data: kept until you delete your account. To delete: Settings → Cloud sync → "Delete account and cloud data", or request deletion at the deletion page without opening the app. We delete the account and its Firestore data; Google may keep short-lived backups for a limited period.
  • GitHub and Start.io data are held by those companies under their own policies.

7. Security

All network traffic uses HTTPS. Cloud access is limited by security rules so each user can only read and write their own data. No method of storage is perfectly secure; keep your device locked and use a token with the minimum scope (repo).

8. Children

The app is not directed to children under 13 (or the minimum age in your country) and we do not knowingly collect their data.

9. Your rights

Depending on where you live (for example GDPR in the EEA/UK), you may have the right to access, correct, delete, export or object to processing of your personal data. Use the in-app deletion, or write to bilalalmomani90@gmail.com.

10. Changes

If this policy changes we will update the date above and, for significant changes, notify you in the app.

LibLink — سياسة الخصوصية

آخر تحديث: 2026-11-24 · المطوّر: Belal Momani · التواصل: bilalalmomani90@gmail.com

LibLink («التطبيق») مدير لمستودعات GitHub (عمليات Git والبناء والإصدارات ومكتبة روابط). توضّح هذه السياسة ما يتعامل معه التطبيق من بيانات. لا نملك خادمًا خاصًا ولا نبيع بياناتك. التطبيق مستقل وغير تابع لشركة GitHub, Inc. ولا لـ Google LLC ولا معتمد منهما. «GitHub» علامة تجارية لشركة GitHub, Inc.

١. بيانات تبقى على جهازك فقط

تُحفظ في التخزين الخاص بالتطبيق على جهازك ولا تُرسل إلينا أبدًا:

  • اسم مستخدم GitHub ورمز الوصول الشخصي (Token) واسم/بريد المؤلف المستخدم في الـ commits.
  • قائمة المشاريع وملفات المستودعات التي تستنسخها أو تنشئها وسجل البناء والإصدارات والمسودات وروابط المكتبة والإعدادات.
  • اختياريًا: بيانات مفتاح التوقيع إن اخترت أن يتذكرها التطبيق لإعادة توقيع APK.

الـ Token محمي بعزل تطبيقات أندرويد ومستثنى من النسخ الاحتياطي. حذف بيانات التطبيق أو إزالته يمسح كل ذلك.

٢. بيانات تُرسل إلى GitHub (بطلبك)

عند السحب أو الرفع أو الاستنساخ أو بدء بناء أو تنزيل ناتج بناء أو عرض المستودعات، يرسل التطبيق الـ Token والمحتوى المطلوب مباشرة إلى GitHub (github.com وapi.github.com) عبر HTTPS. تعالجها GitHub وفق بيان الخصوصية الخاص بها. لا نستلم هذه البيانات.

٣. المزامنة السحابية الاختيارية (Firebase / Google)

إذا — وفقط إذا — أنشأت حسابًا داخل التطبيق (الإعدادات ← المزامنة السحابية)، يستخدم التطبيق Firebase Authentication وCloud Firestore من Google لمزامنة أجهزتك. يُحفظ لحسابك: بريدك الإلكتروني ومعرّف مستخدم وكلمة سرك (تعالجها Firebase مشفّرة ولا نستطيع قراءتها) وعناصر المكتبة وأسماء المشاريع وروابط المستودعات والإعدادات (اسم مستخدم GitHub واسم/بريد المؤلف واللغة). الـ Token يُرفع فقط إذا فعّلت «مزامنة الـ Token» ويُشفَّر على جهازك بعبارة مرور لا تُرسل إلى أي مكان. قد تعالج Firebase بيانات تقنية مثل عنوان IP ومعرّفات التثبيت لتشغيل الخدمة، انظر معلومات خصوصية Firebase. استخدام التطبيق دون حساب لا يرسل شيئًا إلى Firebase.

٤. الإعلانات (الإصدارات التي تحوي إعلانات)

تعرض بعض الإصدارات إعلانات بانر من Start.io. قد تجمع حزمة Start.io وتستخدم معرّف الإعلانات في أندرويد وعنوان IP (والموقع التقريبي المستنتج منه) ومعلومات الجهاز والتطبيق وبيانات تشخيصية لأغراض الإعلان والتحليلات. يسألك التطبيق إن كنت تسمح بالإعلانات المخصّصة، ويمكنك تغيير اختيارك في أي وقت من الإعدادات، كما يمكنك إعادة ضبط معرّف الإعلانات أو حذفه من إعدادات أندرويد. انظر سياسة خصوصية Start.io. لا يحتوي التطبيق على أي حزم إعلانات أو تحليلات أخرى.

٥. الصلاحيات

  • الإنترنت وحالة الشبكة — للاتصال بـ GitHub وFirebase وشبكة الإعلانات.
  • الإشعارات — لإعلامك عند انتهاء البناء.
  • معرّف الإعلانات — تستخدمه شبكة الإعلانات (إصدارات الإعلانات فقط).

لا يصل التطبيق إلى جهات الاتصال ولا الكاميرا ولا الميكروفون ولا الموقع ولا الرسائل ولا سجل المكالمات.

٦. الاحتفاظ والحذف

  • بيانات الجهاز: تبقى حتى تحذفها أو تزيل التطبيق. الملفات التي تحذفها داخل التطبيق تبقى في سلة المحذوفات 3 أيام.
  • بيانات المزامنة السحابية: تبقى حتى تحذف حسابك. للحذف: الإعدادات ← المزامنة السحابية ← «حذف الحساب والبيانات السحابية»، أو اطلب الحذف من صفحة الحذف دون فتح التطبيق. نحذف الحساب وبياناته في Firestore، وقد تحتفظ Google بنسخ احتياطية قصيرة المدة لفترة محدودة.
  • بيانات GitHub وStart.io تحتفظ بها هاتان الشركتان وفق سياستيهما.

٧. الأمان

كل الاتصالات عبر HTTPS. الوصول السحابي مقيّد بقواعد أمان بحيث يقرأ كل مستخدم بياناته فقط. لا توجد طريقة تخزين آمنة تمامًا؛ أبقِ جهازك مقفلًا واستخدم Token بأقل صلاحية (repo).

٨. الأطفال

التطبيق غير موجّه للأطفال دون 13 عامًا (أو الحد الأدنى للسن في بلدك) ولا نجمع بياناتهم عمدًا.

٩. حقوقك

بحسب مكان إقامتك (مثل GDPR في الاتحاد الأوروبي/بريطانيا) قد يحق لك الوصول إلى بياناتك أو تصحيحها أو حذفها أو تصديرها أو الاعتراض على معالجتها. استخدم الحذف من التطبيق أو راسل bilalalmomani90@gmail.com.
