Install steps

  1. Download diskati.exe and SHA256SUMS.txt from the official releases page.
  2. Verify in PowerShell: Get-FileHash .\diskati.exe -Algorithm SHA256 and compare with the matching line in SHA256SUMS.txt.
  3. Run diskati.exe. On first run approve the firewall/administrator prompt so your phone can reach it.
  4. Find its icon near the clock (it may be under “^”). Choose “Pair new phone” to show the code and QR.
  5. Open Bytezen on your phone and enter the code or scan the QR.
Windows SmartScreen: the file is not signed with a paid certificate, so “Windows protected your PC” may appear. This is expected for new programs; verify the hash as above and never download it elsewhere.
