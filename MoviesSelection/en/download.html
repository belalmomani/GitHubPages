How to install

  1. Download MoviesSelection.apk with the button above.
  2. Open it from your download notifications or a file manager.
  3. If Android says installs from this source are blocked, allow it for the app you downloaded from (browser or Files), then go back and finish.
  4. On a TV: copy the file with a USB drive or a file-transfer app and install it from a file manager.

Please note

  • Download the app from this page only. We are not responsible for files from other sources.
  • To update, download the newest file and install it over the old one; your favourites and lists are kept.
  • The app is not currently available on Google Play.

Requirements

  • Android 8.0 (API 26) or newer.
  • An internet connection to fetch title data.
  • A phone or a TV (Android TV / Google TV).
