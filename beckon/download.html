قد يحذّرك نظامك أول مرة. الملفات غير موقّعة رقمياً بعد: ويندوز يعرض «Windows protected your PC» (اختر More info ثم Run anyway)، وماك يقول إنه لا يستطيع التحقق (إعدادات النظام ← الخصوصية والأمان ← Open Anyway).Your system may warn you the first time. The files are not code-signed yet: Windows shows “Windows protected your PC” (choose More info, then Run anyway), and macOS says it cannot verify the app (System Settings → Privacy & Security → Open Anyway).

3. الربط3. Pairing

  1. شغّل Beckon على الحاسوب. تجد أيقونته بجوار الساعة في ويندوز، وفي الشريط العلوي في ماك.Start Beckon on the computer. Its icon is by the clock on Windows and in the menu bar on a Mac.
  2. اختر Pair a phone… ليظهر رمز QR.Choose Pair a phone… to show the QR code.
  3. في التطبيق على الهاتف اضغط إضافة جهاز وامسح الرمز.In the phone app, add a device and scan the code.
  4. الرمز صالح خمس دقائق ويعمل مرة واحدة. اطلب رمزاً جديداً إن انتهى.The code lasts five minutes and works once. Ask for a new one if it expires.

4. التحقق من الملف (اختياري)4. Checking a file (optional)

كل إصدار ينشر قائمة SHA-256 في ملف SHA256SUMS. للتحقق:Each release publishes SHA-256 sums in the file SHA256SUMS. To check:

sha256sum -c SHA256SUMS --ignore-missing
